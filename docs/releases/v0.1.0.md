# CortexShift 0.1.0 — initial public alpha (draft)

**Switch agents. Keep the context.** CortexShift keeps a development Task intact
while native coding agents work sequentially in the same local repository.
The Task outlives provider sessions; structured handoffs combine durable state
with live Git without asking an unavailable outgoing agent to summarize.

This release supports task history, Claude/Codex/Antigravity adapters, manual
handoffs, known-ID native resume, checkpoints/recovery, stdio MCP shared state,
and a Textual terminal control center. Schema v6 and handoff/checkpoint v1 are
the persisted contracts.

The canonical repository is <https://github.com/batuhanasmakaya/CortexShift>.
After publication install with `pipx install cortexshift`. Native providers and
Git are installed separately. Follow [Getting Started](../getting-started.md)
for init → task → run → checkpoint → switch, and run `cortexshift tui` for the
dashboard. Homebrew is pending a custom tap; this draft is not a publication claim.

Real end-to-end validation was performed against authenticated Claude Code 2.1.204
and Codex 0.153.4: managed MCP session binding, managed write tools, session-bound
checkpoint provenance, native session ID capture, native resume, CortexShift
session lineage, and a real Claude to Codex handoff carrying task, objective,
current work, prior session, and a structured decision. Antigravity was not
installed in that environment, so it has no real E2E validation and rests on
deterministic fake-provider coverage alone. Those provider versions are what was
exercised, not a guarantee for other CLI versions.

Provider CLIs may change. Null legacy or plain-run native IDs cannot exact-resume;
Antigravity needs explicit workspace MCP setup. Codex/Antigravity handoffs use a
bootstrap model turn. Native provider usage may consume quota/subscriptions.
Automatic quota switching, embedded provider TUIs, and a GUI are not implemented.
Review [Provider Support](../provider-support.md) for validation status.

CortexShift stores project-local structured data, not transcripts or credentials.
Native providers may send data to their own services. No affiliation with or
endorsement by Anthropic, OpenAI, or Google is implied. This is an alpha with
internal APIs subject to change, not a production-stability claim.

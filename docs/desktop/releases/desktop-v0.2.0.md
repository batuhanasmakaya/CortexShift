# CortexShift Desktop 0.2.0

- Install CortexShift on Apple Silicon macOS from a disk image or on Windows x64 with a per-user installer.
- View the installed Desktop and embedded core versions in Settings & diagnostics. Builds with a configured stable channel can check for signed updates there.
- Desktop keeps your project files, Tasks, Session history, handoffs, and provider authentication local. Installing an update may require finishing native terminal work or reviewing an unresolved Session first.

The embedded CortexShift core is 0.1.0. The existing project schema is v6 and the private bridge protocol is 1.
